## What I work on

I like problems where the constraint is the system, not the feature. Three things keep showing up:

- **Local-first software.** Software that keeps working when the network does not, and treats the device as the primary compute node rather than a thin client.
- **Distributed systems that fail honestly.** Write-ahead logs, conflict escalation instead of last-write-wins, queueing and backpressure.
- **Measurement before claims.** Every project I ship publishes the benchmark, the hardware it ran on, and the run that failed.
